# 🛒 Shopping List Web App

A clean, interactive web application for managing your daily shopping items with real-time filtering and dynamic UI updates.

## 🚀 Features

- **Add Items:** Fast item creation via form submission or keyboard shortcuts.
- **Filter Items:** Real-time search/filtering through your active list.
- **Responsive UI:** Clean interface built with modern CSS and Font Awesome icons.
- **Dynamic DOM Operations:** Smooth event handling driven by Vanilla JavaScript.

## 🛠️ Tech Stack

- **HTML5** — Document structure and form elements
- **CSS3** — Custom styling and layout design
- **JavaScript (ES6+)** — DOM manipulation and event logic
- **Font Awesome** — Vector icons
