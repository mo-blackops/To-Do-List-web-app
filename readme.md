# 🛒 Shopping List Web App

A clean, interactive web application for managing your daily shopping items with real-time filtering, local storage persistence, edit functionality, and dynamic UI updates.

## 🚀 Features

- **Add & Edit Items:** Add new items or click existing ones to update them.
- **Local Storage Persistence:** Keeps your shopping list saved even after refreshing or closing the browser.
- **Duplicate Prevention:** Prevents adding duplicate items to the list.
- **Filter Items:** Real-time search/filtering through your active list.
- **Remove & Clear All:** Delete individual items or clear the entire list at once.
- **Dynamic UI State:** Automatically toggles filter inputs and clear buttons based on list state.
- **Responsive UI:** Clean interface built with modern CSS and Font Awesome icons.

## 🛠️ Tech Stack

- **HTML5** — Document structure and form elements
- **CSS3** — Custom styling and layout design
- **JavaScript (ES6+)** — DOM manipulation, event handling, and Local Storage API
- **Font Awesome** — Vector icons
