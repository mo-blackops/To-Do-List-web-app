# 📝 To-Do List Web App

A clean, interactive web application for managing your daily tasks with real-time filtering, local storage persistence, edit functionality, and dynamic UI updates.

## 🚀 Features

- **Add & Edit Tasks:** Add new tasks or click existing ones to update them.
- **Local Storage Persistence:** Keeps your task list saved even after refreshing or closing the browser.
- **Duplicate Prevention:** Prevents adding duplicate tasks to the list.
- **Filter Tasks:** Real-time search/filtering through your active tasks.
- **Remove & Clear All:** Delete individual tasks or clear the entire list at once.
- **Dynamic UI State:** Automatically toggles filter inputs and clear buttons based on list state.
- **Responsive UI:** Clean interface built with modern CSS and Font Awesome icons.

## 🛠️ Tech Stack

- **HTML5** — Document structure and form elements
- **CSS3** — Custom styling and layout design
- **JavaScript (ES6+)** — DOM manipulation, event handling, and Local Storage API
- **Font Awesome** — Vector icons
